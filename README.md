# 여덟, 가을을 건너다

2026년 순천·여수 가족여행 사진 에세이.

## 구성
- 세 장의 여행 챕터, 패럴랙스 장면, 가로 캐러셀
- 사진 전체 앨범 및 날짜 필터
- 무음 압축 영상, 키보드/스와이프 라이트박스
- 모바일 반응형 및 reduced-motion 지원

## 로컬 확인
`python3 -m http.server 8765 --bind 127.0.0.1`

## 개인정보
공개에 동의한 가족 공유용 앨범입니다. 위치/EXIF 제거, 영상 무음화. 원본 경로와 개인용 명세는 Git 추적에서 제외합니다. robots 설정은 검색 제외 요청이지 접근 통제가 아닙니다.
